# InsightForge AI

**A data analytics portfolio focused on turning raw data into clear, decision-oriented business insights.**

InsightForge AI is a growing portfolio of practical analytics projects built with Python, data analysis, visualization, and interactive reporting. Each case study documents the business question, data preparation, metric definitions, findings, and limitations.

## Featured Project

### Sales & Profit Intelligence

An end-to-end sales analysis case study exploring revenue, product costs, calculated profit, and profit margins across products, categories, regions, and time.

**What this project demonstrates**
- Data validation and quality checks with Python
- Business metric definitions and reusable calculations
- Product, category, and regional performance analysis
- Monthly revenue and calculated-profit trends
- Interactive dashboard filters and visual reporting
- Automated tests and reproducible analysis documentation

**Dataset snapshot**

| Measure | Result |
|---|---:|
| Sales records | 49 |
| Units sold | 890 |
| Revenue after discounts | 39,074.47 |
| Recorded product cost | 22,642.90 |
| Calculated profit | 16,431.57 |
| Overall profit margin | 42.1% |

> **Data and metric note:** The dataset is synthetic and does not represent a real business. Currency is not specified, so amounts are shown in dataset currency units. Calculated profit subtracts recorded product cost only; it excludes operating expenses and taxes and is not net profit.
